# LevelMod

Уровни, миссии и задачи: редактор уровней, локации, чекпоинты, прогоны на одного и нескольких игроков, HUD задач.

Часть набора модов «Смешарики» для Minecraft 26.2 (Fabric, Java 25). Общее описание, установка и состав набора — в [корневом README](https://github.com/NoPasaRun/smeshariki-demo#readme).

Уровни — JSON-файлы в `data/levelmod/levels/` (заготовка «Большое маленькое приключение» входит в мод и копируется при первом запуске). Локации и группы лежат в `data/levelmod/worlds/<мир>/places.json`. В выживании окно уровней только «начать уровень»; редактор, локации и проверка — в творческом режиме.

## Клавиши

| Клавиша | Действие |
|---|---|
| L | окно уровней |
| U | описание миссии («Подробнее») |
| I | описание механики предмета в руке |
| Y | показать / скрыть стрелку к цели |
| V | наблюдатель (пока ждёшь остальных) |

## Сборка

```
./gradlew jar --no-daemon -Dorg.gradle.jvmargs=-Xmx900m
```

Результат — `build/libs/levelmod-1.0.0.jar`. Моды компилируются против соседних jar в `../<Мод>/build/libs/`, порядок сборки: UiLib → GameplayMod, ManagementMod → WorldMod → BehaviorMod, BuildMod → LevelMod.
